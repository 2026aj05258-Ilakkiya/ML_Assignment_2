# ML Assignment 2 — Classification Models

## a. Problem statement
Build and compare five supervised classification algorithms on one public classification dataset, report six evaluation metrics, and provide an interactive Streamlit application for evaluating saved models on labelled test data.

## b. Dataset description
**Dataset:** Breast Cancer Wisconsin (Diagnostic)  
**Original public source:** UCI Machine Learning Repository, Breast Cancer Wisconsin (Diagnostic) Data Set.  
**Dataset information:** 569 instances and 30 numeric input features; binary target. The starter obtains the well-known dataset through `sklearn.datasets.load_breast_cancer`, which bundles the dataset for reproducible experimentation. Confirm the dataset citation and details from the UCI repository before final submission.

**Target encoding in this project:** `0 = malignant`, `1 = benign` (as represented by scikit-learn's dataset). The test CSV contains the target column because evaluation metrics require true labels.

## Run locally / in the lab
1. Install the packages in `requirements.txt`.
2. Run `python train_models.py` once to create saved models and a held-out test CSV.
3. Run `streamlit run app.py`.
4. Open the local URL printed by Streamlit.

## Project files
- `train_models.py`: dataset preparation, split, training, saving models and test CSV.
- `app.py`: Streamlit UI, CSV validation, metrics, confusion matrix, classification report and comparison table.
- `model/`: saved model files and metadata (generated by training script).
- `test_data.csv`: held-out test data (generated by training script).
- `full_dataset.csv`: full dataset for documenting the dataset; don't upload this as the app's test set.
- `requirements.txt`: deployment dependencies.

## Reproducibility and academic integrity
The train/test split uses stratification and `random_state=42` for reproducibility. Models are fitted only in `train_models.py`; the Streamlit app loads saved models and does not retrain them on uploaded data. Review, understand, personalize, and test the code. ### Application implementation note
The Streamlit application loads the five pre-trained model files from the `model/` directory. It evaluates the labelled CSV supplied by the user and does not retrain models on uploaded data. For binary AUC, the app identifies the positive-class probability column from each saved model's `classes_` attribute.
